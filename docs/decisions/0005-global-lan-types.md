# 0005 LAN types are global, clans keep their own details

**Context:** LAN types used to belong to one clan, so a LAN party that several clans go to existed once per clan.

**Decision:** each LAN party exists once per instance, kept by platform admins and support. A clan picks the types it goes to and keeps its own arrangements per type: group spots, seats, answer deadline, reminders and Discord placement. Organizer contacts and to-dos stay per clan too: they are the organizers' own notes and people, which other clans shouldn't see or edit.

**Consequences:** only platform staff change the shared details (name, location, website, ticket shop). Nicks and LAN IDs follow a member into every clan. Introduced in pull request #212.
