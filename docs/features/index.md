# Features

Reference for everything Seatbit does. Each page says who uses the feature and where to find it in the app.

Seatbit has three kinds of users:

- **Members** answer for events, pick seats, offer rides and order food.
- **Leads, clan admins, event managers and recruiters** run the clan and its events. See [roles](clans.md#roles).
- **Platform staff** (owners, admins, moderators, support) run the instance. See [Platform admin](admin.md).

## Conventions in the app

- **Mobile-first.** Every page works on a phone; desktop gets wider layouts, side panels and drag and drop.
- **Dates** are 24h, Swiss style: *Sat 14.11.2026, 18:00*. Every date field is a text box that also takes typed or pasted dates (`14.11.2026 18:00`, `14.11. 18`).
- **People** are shown as *Anna "Nova" Frei*: first name, nick, surname.
- **View / Manage:** clan and event pages have a *View* mode for everyone and a *Manage* mode for people with a role.
